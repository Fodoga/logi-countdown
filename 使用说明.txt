物流倒计时预警台 · 使用说明
================================

【这是什么】
一个纯本地运行的网页工具：每天上传两份源数据，自动算出"物流倒计时预警最终模板"，
并用表格+图表呈现；支持供应商离线反馈"是否已完成发货"、每日看板累计归档、供应商数据隔离。
数据不出电脑，无需联网、无需安装、无需服务器。

【怎么打开】
1. 把整个「物流倒计时预警网页」文件夹发给对方（不要只发 index.html 单个文件）。
2. 对方解压后，双击里面的 index.html，用 Chrome 或 Edge 浏览器打开即可。

【每天怎么用】
第 1 步：准备两个源文件
  - 订单源文件：含 订单号、供应商名称、订单状态、物流状态、付款时间、快递单号、商品名称 等列。
  - 快递源文件：仅含"快递单号"一列，用于剔重（已在快递表的订单视为已发货）。
  - 支持 .xlsx / .xls / .csv。

第 2 步：上传并运行
  - 把两个文件拖入（或点击选择）页面上方对应区域。
  - 点「▶ 开始处理」。上传前会自动预检列名，缺列会红字提示，可按提示修正或强制继续。

第 3 步：查看与导出
  - 页面自动生成：处理概览、可视化看板、倒计时预警最终模板（超36h未发货/距36h不足12h/已发货无物流订单高亮）。
  - 用搜索框与下拉筛选定位订单；点「⬇ 导出 Excel / CSV」保存最终模板。
  - 「⑤ 已剔除明细」可展开查看被筛选/去重掉的订单及原因，也可导出。

【第 4 步：供应商联动反馈（可选，离线闭环）】
  闭环逻辑：经理导出"待确认清单"Excel → 发给供应商 → 供应商在 Excel 里直接填「是否已完成发货」发回 → 经理"导入反馈文件"按订单号合并进主表。整个流程无需联网，靠文件往返完成。**供应商不需要打开本网页**，拿到 Excel 用 WPS/Excel 填完发回即可。

  (A) 最简流程（推荐，供应商不碰网页）：
    - 经理进入「⑥ 供应商联动反馈」，点「📤 导出待确认清单」导出 Excel（含该供应商距36h不足12h/超36h未发货/已发货无物流订单 + 商品名称 + 是否已完成发货空列）。
    - 把 Excel 微信发给供应商；供应商用 Excel/WPS 在「是否已完成发货」列填 已发货/未发货（未发货在「反馈原因」列写原因），发回。
    - 经理点「📥 导入反馈文件」选中该 Excel，系统按订单号合并，主表"供应商反馈"列立即更新，反馈表对应行也更新。
  (B) 供应商自助流程（供应商愿意用网页）：
    - 经理点「📤 导出供应商专属快照」发 JSON；供应商导入后锁定本人视图，在反馈表逐单确认 → 点「📤 导出我的反馈」回传 → 经理「📥 导入反馈文件」汇总。
  (C) 导入修正与注意事项：
    - **导入前必须先「① 上传源数据」并点「▶ 开始处理」拿到当前看板**，否则会提示"请先处理数据再导入"（这是之前"导入不了"的主因）。
    - 导入兼容多种表头（是否已完成发货 / 是否发货 / 反馈状态）与多种填法（已发货/已发、未发货/未发），未匹配到的订单号会保留并提示，不会丢数据。
    - 回传的应是供应商<b>填好的反馈文件</b>，不是你发出的空白待确认清单（空表导入只会产生"待确认"）。
  (D) 反馈区搜索框（按供应商名筛选）：
    - 「⑥ 供应商联动反馈」卡片工具栏的 🔍 搜索框，按**供应商名称**实时过滤，方便在“管理总览”多供应商时快速定位某供应商的距36h不足12h/超36h未发货/已发货无物流订单。

【第 5 步：把最新看板同步给供应商（数据快照，免发源数据）】
  - 你更新源数据、跑出最新看板后，点「📤 导出数据快照」生成几 KB 的 数据快照_日期.json。
  - 把这个 .json 发给供应商；他点「📥 导入数据快照」即可加载你的最新看板（含你已有的反馈记录），不必重发整个文件夹或源数据。
  - 供应商填完反馈导出发你，你「📥 导入反馈文件」汇总，闭环完成。

【第 6 步：供应商隔离视图 / 供应商 Tab（让供应商只看见自己数据）】
  - 顶部「打开方式」下拉就是角色切换：👔 管理总览 / 🏭 供应商视图。**供应商视图即独立的供应商工作台**，无需另做一个网页。
  - 方式一（推荐，最干净）：经理在「⑥ 供应商联动反馈」下拉选好某供应商后，点「📤 导出供应商专属快照」。
    该快照只含此供应商的订单数据 + 标记 targetSupplier。发给该供应商后，他导入即自动锁定为“供应商视图”，只看得到自己（反馈表中也只显示该供应商的距36h不足12h/超36h未发货/已发货无物流订单），且下拉被锁定不可切走。
  - 方式二：供应商自己点顶部「打开方式」切为「供应商视图」，再导入你发的任意快照/上传自己源数据，也只看到自己。
  - 供应商视图下：主表、看板、反馈表、导出都只针对该供应商；累计看板（经理专属）自动隐藏；反馈填完点「📤 导出我的反馈」回传即可。切换为供应商视图时会自动展开「⑥ 供应商反馈」并滚动到该区，直接进入工作台。
  - 经理端切回「管理总览」即恢复全部数据与累计看板。

【第 7 步：每日归档与累计汇总看板】
  - 每天处理完数据后，进入「⑦ 累计汇总看板」，点「📅 归档今日看板」。
    系统把当天的 per-供应商指标（累计总单/超时/不足12h/未发货反馈/已发货反馈/完成/取消/缺付款时间）存入本地。
  - **归档只统计"今日有风险订单"的供应商**：即超36h未发货>0 或 距36h不足12h>0 的供应商才计入累计；无风险的供应商当日不进累计看板（避免累计被大量正常单稀释）。
  - 同一天重复归档会覆盖当天；跨天自动累加。
  - 看板按供应商展示「累计超时单数」排名与超时率，并用柱状图可视化；顶部概览卡显示累计超时/不足12h/未发货反馈/总单/归档天数。
  - 「🗑 清空累计数据」：一键清空全部已归档历史（带确认弹窗，不可恢复），清空后看板与概览卡归零。
  - 点「⬇ 导出累计汇总」可把全部历史累计导出为 Excel，用于周报/月报。
  - 数据存浏览器本地（localStorage），换电脑/清缓存会丢失，重要累计请定期导出留存。

【板块折叠】
  - 每个内容卡片标题栏右侧有 ▾ 折叠按钮，点标题即可收起/展开；折叠状态自动记忆（localStorage），下次打开保持。
  - 首次进入网页时，除「① 上传源数据」外其余板块默认收起，页面更清爽；用到哪块点开哪块即可。

【不想先找文件？】
  - 点「🎲 一键生成示例演示」立即看效果。
  - 或点「⬇ 下载示例数据」下载两份示例 .xlsx，用它们试上传。

【注意事项】
  - 筛选/去重规则与本地「订单处理工具」(process_orders.py) 完全一致：
      ① 删除 9 家湖南供应商整行；
      ② 订单状态仅保留「已发货 / 待发货」，其余（已收货/取消/退款/已完成等）删除；
      ③ 物流状态仅保留「空白 / 无物流(任意重复)」，其余（运输中/派送中/已签收/已完结等）删除；
      ④ 快递单号出现在快递表的订单视为已发货，整行删除（去重）。
  - 订单号、快递单号全程以"文本"保存，绝不会被改动（前导零、长数字都原样保留）。
  - 最晚发货时间 = 付款时间 + 1.5 天（36 小时）；剩余<0 为“超36h未发货”，剩余<12 小时为“距36h不足12h”。
  - 订单状态为“已发货”但物流状态含“无物流”时，单独标记为“🚚 已发货无物流”（已标记发货、但缺快递单号，需督促补录），不会再被误算成“超36h未发货/距36h不足12h”。
  - 付款时间缺失的订单，倒计时显示"缺付款时间"，不会被误判为超时。
  - 若对方浏览器太老、读取 .xlsx 报错，可先把源文件另存为 .csv 再上传（csv 兼容性最好）。
  - 反馈记录与累计历史保存在浏览器本地（localStorage），换电脑/清缓存会丢失，重要数据请及时导出汇总。
  - 供应商专属快照通过 targetSupplier 字段实现隔离，供应商即使拿到完整文件夹也只能看自己数据。
