# 物流倒计时预警台 · Logi Countdown

> 纯本地、零依赖的物流发货时效监控网页工具 —— 导入订单 Excel，自动算最晚发货时间、剩余倒计时、风险预警，并支持供应商联动反馈与每日累计归档。

🌐 **在线演示**：https://fodoga.github.io/logi-countdown/
📦 **源码**：https://github.com/Fodoga/logi-countdown

---

## ✨ 功能特性

| 模块 | 说明 |
| --- | --- |
| ⏱️ 发货时效监控 | 导入订单表（Excel / CSV），按「付款时间 + 1.5 天」自动算出**最晚发货时间**与**剩余倒计时** |
| 🚦 状态智能判定 | 自动标记：`✅ 正常` / `⚠️ 紧急(不足12h)` / `❌ 已超时` / `✅ 已完成` / `⛔ 已取消` / `🚫 无物流` |
| 📊 可视化看板 | 状态分布甜甜圈图、Top10 风险供应商柱状图（占满整行）、实时概览卡 |
| 🤝 供应商联动反馈 | 独立反馈表，记录发货沟通 / 异常说明，与主表联动 |
| 🗂️ 每日累计归档 | 一键归档当日汇总，**localStorage 持久化**，第二天重开页面数据仍在 |
| 👥 角色切换 | 普通用户 / 管理员（管理员可见累计归档区） |
| 🔍 流畅检索 | 搜索防抖 + 表格分页，上千行也不卡顿 |

## 🚀 使用方式

**方式一：直接打开在线版（推荐）**
前往 👉 https://fodoga.github.io/logi-countdown/ ，点击「导入」选择订单 Excel 即可。

**方式二：本地离线运行**
1. 下载本仓库（或 `物流倒计时预警网页_分享版.zip`）并解压
2. 双击 `index.html` 用浏览器打开（**无需联网、无需安装任何环境**）
3. 点击「导入数据」，选择包含订单信息的 Excel / CSV 文件

> 数据列名规范、字段说明见仓库内 `使用说明.txt`。所有数据仅在你的浏览器本地处理，不会上传到任何服务器。

## 🛠️ 技术说明

- **纯前端**，零后端、零构建步骤，原生 HTML / CSS / JavaScript
- 图表使用 Canvas 手绘（甜甜圈 + 柱状），无第三方图表库
- Excel 解析为自研轻量解析器，离线可用
- 累计归档通过 `localStorage` 持久化
